# YouTube Transcriber

Programa en Python para obtener la transcripción de un video de YouTube entre un intervalo de tiempo específico.

## Requisitos

- Python 3.10 o superior

## Instalación

```bash
pip install -r requirements.txt
```

## Uso

Edita el archivo `transcribir.py` y cambia:

```python
video_id = "KQFPzJX4CsE"

start_time = 745
end_time = 1708
```

Luego ejecuta:

```bash
python transcribir.py
```

La transcripción se guardará en `transcripcion.txt`.
